# Even and Odd Number Checker

## Project Description
This is a simple C++ program that determines whether an integer entered by a user is even or odd.

## Features
- Accepts integer input from the user.
- Checks whether the input is valid.
- Determines whether a number is even or odd.
- Displays an appropriate result.

## Technologies Used
- C++
- Standard Input/Output Library (iostream)

## How to Run

1. Compile the program:

   `g++ even_odd_checker.cpp -o even_odd_checker`

2. Run the executable:

   `./even_odd_checker`
